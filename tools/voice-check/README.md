# Задача 0.1 — проверка голоса и хостинга

Самая важная проверка проекта. Если русский голос на телефоне окажется облачным,
офлайн-PWA с синтезом речи не работает, и «Голос папы» надо переносить из этапа 2
в этап 1 — до того, как написана хоть одна игра.

## Как запустить

```bash
npx --yes http-server tools/voice-check -a 0.0.0.0 -p 5173 -c-1
```

На телефоне открыть: **http://192.168.0.125:5173**
(телефон и компьютер — в одной Wi-Fi сети; если адрес сменился, посмотреть свой:
`Get-NetIPAddress -AddressFamily IPv4`)

HTTPS здесь не нужен: Web Speech API работает и по http. HTTPS понадобится
позже — для установки PWA и service worker (задача A1).

### 2. Ударение

Нажать обе кнопки в каждой паре (за́мок/замо́к, му́ка/мука́, кру́жки/кружки́,
пла́чу/плачу́). Синтез почти наверняка прочитает пары одинаково — это ожидаемо
и само по себе не блокирует. Важно записать, читает ли он верно хотя бы
**обычные слова урока** (раздел 2): «вокза́л», «трава́», «коро́ва».

| Проверка | Результат |

## РЕЗУЛЬТАТ ПРОГОНА (телефон дочки)

| Проверка | Результат |
| --- | --- |
| Голосов на устройстве | один, не Irina (Irina — десктопный голос Windows) |
| Имя голоса | *не записано* |
| **Звучит ли в авиарежиме** | **ДА — голос на устройстве, офлайн работает** |
| Различает пары по ударению | нет — ожидаемо, не блокирует |
| **Ударение в обычных словах урока** | **верное** — «вокза́л», «трава́», «коро́ва» |
| «корова» в режиме «как пишем» | **«КАрова» — редукция безударной О** |

### Аканье: все пять обходов провалились

| Способ | Результат |
| --- | --- |
| A · слоги отдельными фразами | А |
| B · то же, медленно (0.5) | А |
| C · одна фраза через точки | А |
| D · знак ударения U+0301 | А |
| E · по буквам отдельными фразами | А |

**Вывод**: движок применяет редукцию безусловно. Из браузера это не обходится.
Орфографическое проговаривание (§2 ТЗ) на синтезе невозможно.

### Что это значит

Синтез остаётся пригоден там, где редукция — **правильное** поведение:

| Применение | Синтез годится? |
| --- | --- |
| Инструкции к заданиям | да |
| Режим «как говорим» | да — аканье здесь и нужно |
| Аудиодиктант (слышит слово, пишет) | да — в этом и смысл диктанта |
| Режим «как пишем» | **нет, нужна запись** |

Решение: «Голос папы» переезжает в этап 1, но **только для режима «как пишем»**.
8–15 слов на урок, порядка 2–3 минут записи. Интерфейс `speak()` из плана
такое разделение допускает — игры переписывать не придётся.

## Развилка по итогам

- **Голос звучит в авиарежиме** → план идёт как есть, `speak()` на синтезе.
- **Тишина в авиарежиме** → «Голос папы» переезжает в этап 1 (блок E, +3 сессии).
  Интерфейс `speak()` из плана это уже предусматривает — игры переписывать не придётся.
- **GitHub Pages не открывается без VPN** → берём площадку из таблицы, которая открылась.

## Побочная находка: слогоделение

В странице есть черновик алгоритма слогоделения — он переедет в `engine/syllables.ts`
(задача B5). Сейчас проходит 21 из 24 тестовых слов.

Всплыл вопрос, который надо решить в B5: в русском приняты **два разных деления**,
и они расходятся:

| Слово | Школьный перенос | Фонетический (открытый) слог |
| --- | --- | --- |
| земля | зем-ля | зе-мля |
| сестра | сес-тра | се-стра |
| объявление | объ-яв-ле-ни-е | объ-я-вле-ни-е |

Для режима «как пишем» надо выбрать тот вариант, которому её учат по Канакиной,
иначе приложение будет проговаривать слова не так, как учительница в классе.
**Посмотреть в учебнике до задачи B5.**
