# Словари из учебника

«Русский язык, 4 класс», Канакина, **часть 2**, страницы 152–155. Задача 0.5.

Эта версия снята со скриншотов PDF и читается точно. Она заменяет первую
расшифровку, сделанную с фотографии под углом: там был обрезан левый край
страницы и терялись слова.

**Полужирным** в учебнике выделены слова, которые изучаются именно в 4 классе.
Остальные — из прошлых лет, они идут на повторение.

### Слышим одно, пишем другое

Учебник помечает произношение в квадратных скобках. **Для приложения это золото**:
здесь расхождение между звучанием и написанием доведено до предела — ровно то,
на чём строится орфографическая зоркость.

| Слово | Произносится |
| --- | --- |
| компьютер | [т] |
| конечно | [шн] |
| музей | [з'] |
| партер | [т] |
| свитер | [т] |
| скучно | [шн] |
| теннис | [т] |
| фанера | [н'] |
| что, чтобы | [шт] |
| шоссе | [сэ] |
| яичница | [шн'] |

В диктант такие слова брать осторожно: ребёнку легко запутаться. Зато они
отлично подходят для разговора о том, почему слово нельзя писать «как слышится».
