# Словоград

Детское офлайн-приложение для тренировки орфографии, 4 класс.
Родитель фотографирует школьное задание, Claude собирает из него урок,
ребёнок играет по 10–15 минут в день. Полное ТЗ — [docs/SPEC.md](docs/SPEC.md).

Сейчас пройден **этап 0** — проверка идеи. Приложения ещё нет, есть инструменты
и результаты проверок, на которых строится этап 1.

## Что где лежит

| Папка | Что это |
| --- | --- |
| `docs/SPEC.md` | Техническое задание |
| `docs/plans/stage-1.md` | План разработки по задачам на 20 минут |
| `docs/orthogram-catalog.md` | Каталог из 28 орфограмм, сверенный с памятками учебника |
| `docs/playtest-log.md` | Что сказала дочка, когда играла, и что из-за этого изменено |
| `tools/skill/` | Генератор уроков для claude.ai: инструкция, схема, словари, проверялка |
| `tools/imposter/` | Игра «Кто самозванец?» — один файл, работает офлайн |
| `tools/voice-check/` | Страница проверки синтеза речи на телефоне |
| `data/` | **Содержимое, которое видит приложение**: `index.json` (что активно, исключённые и трудные слова), `lessons/` (уроки), `manual.json` (слова, добавленные руками). Правится здесь — у ребёнка обновляется при запуске игры с интернетом |

## Проверить урок

```bash
node tools/skill/check-lesson.mjs data/lessons/upr111.json
```

Ловит то, чего не видит JSON Schema: буква-ответ не на своём месте, ударение
не на гласной, проверочное слово не подходит, объяснение слишком длинное.
Код возврата 1, если есть нарушения, блокирующие импорт.

## Что уже выяснено на практике

- **Синтез речи не годится для проговаривания по слогам.** Голос на телефоне
  работает офлайн, но безударную «о» читает как «а»: «КАрова». Пять обходов не
  помогли. Поэтому режим «как пишем» будет на записи голоса родителя,
  а синтез остаётся на инструкциях и обычном произношении.
- **Каталог орфограмм из ТЗ был неполон.** Сверка с памятками обеих частей
  учебника добавила 10 кодов, включая всю группу суффиксов.
- **Тексты для ребёнка нужно писать короче и обычными словами.** Правила
  в скилле: до 25 слов, без придуманных терминов, обращение к девочке,
  буквы под вопросом выделяются как `{е}`.
